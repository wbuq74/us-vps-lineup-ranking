## 榜单不会告诉你的三笔账

**促销价和续费价是两个数。** RackNerd 的低价来自节日活动，活动套餐有时效性，常驻方案价格更高。复购时还有个容易踩的坑：新机器的密码以你首次开通时收到的那封邮件为准，别翻遍邮箱找“新密码”。

**同一家商家，不同机房可能是两种产品。** V.PS 的圣何塞机房是三网全高端，西雅图和纽约机房却是常规国际线路。搬瓦工同理：CN2 GT款年付49.99美元起，GIA-E年付169.99美元起，120美元的差价买的就是晚高峰不堵——CN2 GT 在晚间也已经比较拥堵。认准机房和线路，比认品牌更重要。

**“不限流量”和“大流量”是两回事。** RakSmart 的不限流量配的是独享带宽和高端线路定价；ColoCrossing 的40TB年付是把单价做到极致的跑量方案，速度和稳定性别按第一档的预期去要求。
